Chapter Rewind for The Walking Dead: The Telltale Definitive Series
Version @VERSION@ - https://github.com/infernokun/TWD-Definitive-Rewind

Adds chapter rewind to Seasons 2, 3 and 4 of the Definitive Series. No game file is replaced.

BEFORE YOU START
  Rewinding deletes every save after the point you pick, including later episodes.
  To keep a playthrough, copy your save folder first:
    Documents\Telltale Games\The Walking Dead Definitive

INSTALL WITH THE TELLTALE MOD LAUNCHER (recommended)
  1. Get the launcher (version 0.7.0 or newer):
     https://github.com/infernokun/TelltaleModLauncher/releases
  2. If the Season 2-only 1.x version of this mod is installed, remove it in the launcher first.
  3. Open the launcher, pick The Walking Dead: The Telltale Definitive Series,
     and drop this zip onto the window (or use Add mod). Don't extract it.

INSTALL BY HAND
  1. Extract this zip.
  2. Copy these six files into the game's Archives folder,
     for example ...\steamapps\common\The Walking Dead The Telltale Definitive Series\Archives
       WDC_pc_Mod_TWDRewind_S2_data.ttarch2
       _resdesc_50_Mod_TWDRewind_S2.lua
       WDC_pc_Mod_TWDRewind_data.ttarch2
       _resdesc_50_Mod_TWDRewind.lua
       WDC_pc_Mod_TWDRewind_S4Game_data.ttarch2
       _resdesc_50_Mod_TWDRewind_S4Game.lua
  3. If you had 1.x installed, delete WDC_pc_Mod_S2Rewind_data.ttarch2 and
     _resdesc_50_Mod_S2Rewind.lua from the same folder.
  (modinfo_twd_rewind.json is only for the mod launcher. You don't need to copy it.)

USING IT
  Season 2: pick an episode to see the chapter panels and REWIND.
  Season 3: select an episode, open More Options, choose Rewind.
  Season 4: select an episode and press Rewind (left face button) or Restart Episode.
            Previous / Next or the Left / Right arrow keys browse the rewind points,
            Tab shows them all, Esc closes.

UNINSTALL
  Remove it in the launcher, or delete the six files from the Archives folder.
